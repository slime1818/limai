### Lessons learned voor Fase 2 handoff

**Substep 4 composite-pick**. Visual-verify de kandidaat VOOR de copy naar public/biomes/, niet erna. De eerste keuze (apu-composite.webp zonder framing-rock layer) kostte meer iteraties dan nodig. Voor Puna en volgende biomes: render alle composite-variants naast elkaar ter selectie voordat er ook maar een byte naar runtime verhuist. Dit spiegelt de visual_read_calibration learning uit de art-gen fase.

**Layout op 4:3 asset in wider viewports**. Full-width plus bottom-crop gekozen boven pillarbox L/R na user-feedback. Widescreen composite-variant (16:9 of 21:9) is open als pre-launch polish, niet Fase 1 of 2 scope. De math-contradictie "painting w-full plus bands boven/onder op 4:3 image in wider viewport" is genoteerd; enig pad naar banden boven/onder zou een wider-aspect painting vereisen.

**Vercel deploy-pipeline**. Byte-identieke edge delivery binnen ongeveer 45 seconden push-to-live. GitHub webhook plus auto-deploy is strak. Turbopack hash-deterministische output betekent dat lokale CSS chunk hash byte-exact matcht met de live chunk hash, makkelijk te verifieren voor deploy-completeness.

**Claude Code plus dangerous-permissions flow was productief**. Olivier actief in review-loop voor visuele en architecturale beslissingen, Claude Code autonomous op mechanics: builds, Playwright screenshots, commits, push, Vercel monitoring via Monitor tool hash-polling.

**Windows zombie next start**. `taskkill` nodig na elke dev of production server run op Windows, zelfs met with_server.py cleanup. Child node-processen bleven op :3000 plakken. Vaste check voor volgende fase: netstat grep op 3000 voor elke build of screenshot run.
