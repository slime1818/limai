## Approach

Werkvorm per substep varieert:

- **Brainstorm plus review** (substep 1 content-drafts): Olivier plus Claude in chat samen drafts bouwen, Abdul reviewt batches. Iteratief.
- **Implementatie** (substeps 2, 3, 4, 5, 6, 7, 8): Claude Code solo of met Olivier's directe guidance, Abdul levert assets aan waar nodig.

Abdul-betrokkenheid via 3 expliciete touchpoints om zijn tijd-investering voorspelbaar te houden. Geen doorlopende ping-pong.

Volgorde van substeps is ontworpen voor dependency-chain: content eerst (1-3), dan backend plus metadata (4-5), dan operational layers (6-7), dan launch-gate (8).

Brainstorm draft-copy per biome in samenwerking Olivier plus Claude chat. Claude Code assistent voor specifieke tasks (format, copy-edit, cross-biome consistency check).

Per biome content-needs:

- **Puna (Wie we zijn)**: Founder-verhaal Olivier plus Abdul. Achtergrond, waarom LimAI, wat de Andes-referentie voor hen betekent. Lengte 2 tot 3 alinea's.

Deliverable: `docs/content-drafts/[biome].md` per biome file. Draft-status, niet direct voor code-integratie.

**Abdul-touchpoint 1**: drafts-review in één pass na Olivier plus Claude preparation. Efficient, Abdul leest plus geeft feedback in batch.

### 4. Contact form backend

Solo-uitvoerbaar door Claude Code plus Olivier.

- Resend account setup plus API key in Vercel env variables (`RESEND_API_KEY`).
- Nieuwe API route `app/api/contact/route.ts` met form-handler. Valideert input, roept Resend API aan, returnt success of error status.
- Email-template voor notificatie aan Olivier plus Abdul. Styled HTML template of plain text, matcht LimAI brand minimalisme.
- UI states in contact form component: idle, loading spinner, success-bericht, error-melding. Reuse warm-white plus andes-copper palette.
- Anti-spam: honeypot-field plus basic rate-limiting (Vercel edge middleware of in-memory counter).
- End-to-end test: form submission plus email received verify via inbox.

### 5. SEO pass (na content live)

Solo-uitvoerbaar, vereist substeps 2 plus 3 klaar zodat copy definitief is.

- Per-route meta-tags (title plus description) via Next.js `metadata` export in `app/page.tsx` plus per subpage.
- JSON-LD structured data: `Organization` plus `WebSite` plus `CreativeWork` per case. Injected via `<script type="application/ld+json">` in layout.
- `og:image` generatie: 1200x630 PNG render van homepage-hero via Playwright of designed in Canva. One image cross-biome, of per-biome variant.
- `hreflang` plus `alternate` tags (NL primary, EN toekomstig).
- Dynamic `sitemap.xml` via Next.js `app/sitemap.ts` convention.
- `robots.txt` met sitemap-pointer.
- Canonical URLs per route.

### 6. Analytics setup

Solo-uitvoerbaar. Privacy-friendly past agency-positionering plus GDPR-minimalisme.

Keuze: **Plausible** (SaaS, 9 EUR per maand, zero-cookie, EU-hosted) of **Umami** (self-host, gratis, eigen-infra).

**Recommendation: Plausible** want launch-ready zonder hosting-infrastructuur. De 9 EUR per maand is een minieme overhead voor agency-grade analytics en past bij LimAI's privacy-first positionering.

- Script integratie via Next.js `<Script>` component in root layout.
- Goals: CTA-click per biome, form-submit op contact, scroll-depth milestones.
- Custom events: `biome-view` bij elke biome-entry (via `useActiveBiomeIndex` hook trigger), `dot-click` bij ScrollProgressDots (substep 17 equivalent), scroll-milestones (25%, 50%, 75%, 100% van page).
- Dashboard access voor Olivier plus Abdul (Plausible team-member invite).

### 7. Performance plus accessibility audit

Solo plus Claude Code uitvoerbaar.

**Performance:**

- Lighthouse desktop plus mobile, target 90+ alle categories (Performance, Accessibility, Best Practices, SEO).
- Core Web Vitals via PageSpeed Insights: LCP onder 2.5s, CLS onder 0.1, INP onder 200ms.
- Bundle-size check via `npm run build` output, splitting per biome-component indien nodig.

**Accessibility:**

- Keyboard navigation pass: Tab-order through CTAs plus contact form, focus-indicators zichtbaar, skip-to-content link bovenaan.
- Screen-reader pass via VoiceOver (macOS) of NVDA (Windows): alt-texts correct per biome, heading-hierarchy `h1` naar `h2` logisch, ARIA-labels op interactive elements.
- Color contrast audit: WCAG AA minimum, AAA waar mogelijk (tekst op scrim, accent-kleuren).
- `prefers-reduced-motion` respect verificatie (al toegepast in motion guards in ImageStack, confirm via browser setting).

Fixes per issue committed apart, zodat post-launch regression-check makkelijk blijft.

- Global error boundary (`app/error.tsx`) met fallback-UI.
- Social share preview test via real posts op Twitter, LinkedIn, WhatsApp, Slack. og:image moet crisp renderen per platform.
- Performance baseline capture: Lighthouse scores plus PageSpeed metrics vastgelegd voor post-launch vergelijking.
- **Abdul-touchpoint 3**: final launch go/no-go. Formele greenlight voor public-announcement plus social-posts.

Lock-commit hash noteren, Fase 2.5 complete verklaren, door naar Fase 3 polish (particles plus authored T4 drama plus accessibility deepening).
